# Frequency lists

Reference vocabulary ordered from most to least frequent. Each UTF-8 text file
contains one word or multiword expression per line and has no header.

The filenames retain the dataset's `_5000` naming, but they do not all contain
exactly 5,000 rows. The current files contain:

- Czech: 3,250 unique entries
- English: 4,950 unique entries
- Vietnamese: 5,000 unique entries

Keep the order stable when consuming these files: the line position is the
frequency rank. These files were supplied directly for this repository. When
replacing or extending them with a third-party dataset, include its source and
licensing information in the same change.
